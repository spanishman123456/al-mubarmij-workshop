# تقرير ضمان الجودة — أداة التحكم في ظهور الكود (المرحلة الأولى)

## النطاق المنفَّذ

- المستويات الثمانية لظهور الكود.
- النطاقات: عام / مشروع / يوم، مع أولوية مشروع > يوم > عام.
- حماية API الطالب (المحتوى المسموح من الخادم، لا تسريب للحل).
- صفحة إدارة داخل لوحة المعلم `/teacher/code-visibility` + زر في مختبر بايثون.
- معاينة كطالب، نافذة تأكيد قبل كشف الحل الكامل، سجل تغييرات، تراجع/استرجاع.
- اختبارات Unit + Integration + Playwright.

مؤجّل للمرحلة الثانية: تخصيص طالب/مجموعة، محرّر إخفاء الأسطر، الجدولة الزمنية.

## عزل الاختبارات

أُضيف دعم `PLATFORM_SETTINGS_PATH` في `platformSettingsRepository` (افتراضيًا المسار
الحالي) ليستخدم كل ملف اختبار تكامل ملف إعدادات مستقلًّا، تفاديًا لتعارض التوازي على
الملف المشترك. لا تغيير في سلوك الإنتاج.

## منع تسرّب الحل

- الحماية على الخادم عبر `buildAllowedContent`؛ لا يُرسَل الحل إلا في المستوى 8 (فوري)
  أو 7 (بعد المحاولة).
- الدور يؤخذ من الجلسة لا من رأس `X-User-Role` (لا انتحال).
- المسار بلا جلسة يُرفض 401؛ مسارات التعديل للمعلم فقط (403 للطالب).
- عند فشل تحميل السياسة: سقوط إلى المستوى 1 (إخفاء).

## توكيدات

- لم تُعدَّل إعدادات Render ولا متغيّرات البيئة.
- لم يُغيَّر `publishedDays` ولا سياسة النشر ولا تقدّم الطلاب.
- الإعدادات تنعكس فورًا دون Build أو Deploy جديد.
