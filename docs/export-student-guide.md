# دليل التصدير للطالب

احفظ المشروع وشغله أولًا، ثم افتح «تصدير المشروع»:

1. راجع الاسم والوصف والإصدار واتجاه العرض.
2. اختر إظهار الاسم أو اسمًا مستعارًا أو إخفاء اسم المطور.
3. أصلح مشكلات «فحص الجاهزية».
4. اختر Source ZIP أو WebApp أو PWA.
5. عند Windows تابع حالة job من «سجل صادراتي».

لا تشارك download token. تطبيق Windows هو WebApp مغلف بـTauri وليس برنامج
CPython.
