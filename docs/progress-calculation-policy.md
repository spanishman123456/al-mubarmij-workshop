# سياسة احتساب تقدم الطالب

## الإصدار
`progressVersion: v2`

## المصدر الرسمي (Source of Truth)
- **قاعدة البيانات المركزية (SQLite)** هي المصدر الوحيد لاحتساب النسبة.
- `localStorage` يُستخدم للتخزين المؤقت ودمج الجلسة فقط، ويُزامَن إلى الخادم عبر `POST /api/progress/sync`.
- الخادم يحسب النسبة عبر `ProgressCalculationService` — لا يُقبل `progressPercent` من المتصفح.

## المعادلة
```
نسبة التقدم في المحتوى المتاح =
  (العناصر الإلزامية المكتملة المنشورة ÷ إجمالي العناصر الإلزامية المنشورة) × 100
```

## العناصر الداخلة في الحساب (حسب `PUBLISHED_DAYS`)
| الفئة | أمثلة | إلزامي |
|-------|--------|--------|
| التمهيد | BINGO، 4 اتفاقيات | نعم |
| دروس منشورة | دروس اليوم 1…N | نعم |
| أوراق عمل منشورة | `ws-day-01` … | نعم |
| اختبارات يومية | `quiz-day-01` … | نعم |

## مستبعد من الحساب الإلزامي
- **التقويم القبلي (`quiz-pre`)** — تشخيصي فقط، لا يحجب ولا يخفض النسبة.
- **التقويم البعدي** — ليس جزءًا من شريط التقدم المتاح.
- **أيام/دروس غير منشورة** (`draft` أو `PUBLISHED_DAYS` أقل من رقم اليوم).
- **مشاريع micro:bit والمشروع النهائي** — تُعرض كإحصائيات منفصلة (ليست في المقام حاليًا).
- **تسجيل الدخول وحده** — لا يُحتسب إكمالًا.

## مؤشران منفصلان
1. **التقدم في المحتوى المتاح** — النسبة والعناصر الإلزامية المنشورة.
2. **المسار الكامل** — «اليوم X من أصل 15 يومًا» (لا يُعرض 0% إذا أُنجز جزء من اليوم الأول).

## حالة النشاط
| المفتاح | الوصف |
|---------|--------|
| `active_now` | نشاط خلال 5 دقائق |
| `active_today` | نشاط خلال 24 ساعة |
| `recently_active` | خلال 3 أيام |
| `inactive` | لا يوجد نشاط حديث (مع سجل دخول سابق) |
| `not_started` | لم يبدأ |

> لا تُستخدم كلمة «غائب» إلا إذا وُجد نظام حضور رسمي — حاليًا تُستبدل بعبارات دقيقة.

## واجهات API
- `GET /api/progress/me` — تقدم الطالب المحسوب
- `GET /api/progress/me/details` — تفاصيل العناصر
- `GET /api/teacher/students/:studentId/progress` — تقدم طالب للمعلم
- `GET /api/progress/teacher/roster` — جميع الطلاب
- `POST /api/progress/recalculate` — إعادة احتساب (معلم)
- `POST /api/progress/sync` — مزامنة blob + إعادة حساب

## إعادة الاحتساب
```bash
npm run recalculate:progress
```
- ينشئ نسخة احتياطية من قاعدة البيانات أولًا.
- Idempotent — لا يضاعف السجلات.
- يكتب `_computedProgress` داخل `student_progress.progress_json`.
- يسجل في `progress_calculation_log`.
