# نموذج أمان التصدير

يفحص validator imports والمكونات والأصول والأحجام، ويزيل أرقام الهوية والرموز
والأسرار من metadata. لا يشغّل Build Worker `main.py`؛ يفك WebApp ويغلف الملفات
فقط.

عمليات worker والحالة والتنزيل محمية capability tokens عشوائية مخزنة كـSHA-256.
روابط التنزيل تنتهي، والملفات تنظف وفق TTL. لا تزال نسخة الخادم الحالية بلا
نظام حسابات خادمي؛ لذلك سجل ownerId selector غير مصادَق ولا يجب أن يحتوي بيانات
حساسة. الوصول الفردي إلى source/status/artifact محمي بالتوكن.
