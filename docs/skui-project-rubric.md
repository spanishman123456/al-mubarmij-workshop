# Rubric اعتماد مشروع skui النهائي

**الحد الأدنى للاعتماد:** 85/100  
**شرط إضافي:** لا يوجد خطأ Runtime أو فشل أمني أو فشل في المسار الأساسي، مهما كانت الدرجة.

## توزيع الدرجات

### الفكرة والأصالة — 20

- 17–20: فكرة مميزة، مشكلة واضحة، قرارات متعددة، وقابلة للعرض.
- 13–16: فكرة جيدة مع بعض العناصر المعتادة.
- 8–12: تطوير محدود لفكرة تدريبية.
- 0–7: عملية واحدة أو نسخة مباشرة من مثال شائع.

### القيمة وحل المشكلة — 15

- 13–15: هدف ذو معنى ونتائج تفسر أثر قرارات المستخدم.
- 10–12: قيمة تعليمية واضحة لكن الأثر محدود.
- 6–9: تعلم مكوّن أو مهارة منفردة.
- 0–5: لا توجد مشكلة أو نتيجة ذات معنى.

### المنطق البرمجي — 20

- 17–20: خوارزميات وحالة متعددة المراحل وحواف واختبارات جيدة.
- 13–16: منطق متوسط مع وظائف وقوائم وشروط مترابطة.
- 8–12: شروط ودوال بسيطة دون نظام متكامل.
- 0–7: تنفيذ مباشر أو ثابت.

### التفاعل وتجربة المستخدم — 15

- 13–15: onboarding ومساحة عمل وتغذية راجعة ومراحل ونتيجة وإعادة لعب.
- 10–12: تفاعل جيد لكن بعض الحالات أو الإرشاد ناقص.
- 6–9: نموذج أو أزرار محدودة.
- 0–5: ضغطة واحدة أو مسار غير واضح.

### التصميم البصري — 15

- 13–15: هوية مستقلة، تخطيط مناسب، Responsive، حالات مرئية متكاملة.
- 10–12: تصميم متماسك لكنه يعتمد جزئيًا على القالب العام.
- 6–9: Card مركزية مع تغيير الألوان.
- 0–5: قص أو تمرير سيئ أو عدم اتساق.

### الاستقرار والأخطاء — 10

- 9–10: كل السيناريوهات ناجحة ولا أخطاء Runtime، مع اختبارات كاملة.
- 7–8: مستقر مع فجوات اختبار غير حرجة.
- 4–6: أخطاء حواف أو إعادة تشغيل.
- 0–3: خطأ Runtime أو فقد حالة أو مسار أساسي فاشل.

### التصدير والتوافق — 5

- 5: المنصة وWebApp وZIP ناجحة، وPWA/Windows ناجحان عند توفرهما.
- 4: المنصة وWebApp وZIP ناجحة مع هدف غير متاح موثق.
- 2–3: المنصة ناجحة لكن التصدير مختبر جزئيًا.
- 0–1: التصدير يفشل أو يستخدم Runtime مختلفًا.

## قواعد الاستبعاد الفوري

يحصل المشروع على `blocked` ولا يُعتمد إذا:

- ظهر خطأ Runtime في أي مسار قبول.
- شاهد الطالب الحل الكامل.
- فشل reset/replay.
- قُطعت عناصر أساسية على Mobile.
- فشل WebApp أو ZIP.
- فقدت نتيجة المستخدم أو أصبحت الحالة غير متسقة.
- كانت الفكرة مجرد تدريب مصغر مهما بلغت جودة ألوانه.

## تطبيق أولي على المشروعات الحالية

لا تُمنح المشروعات الحالية تقييم اعتماد نهائي قبل إكمال QA. وبناءً على نطاقها الحالي، جميعها تقع في فئة التدريب المصغر؛ حتى المشروعات الأفضل بصريًا لا تحقق شروط الفكرة والمراحل والتفاعل وإعادة الاستخدام اللازمة للوصول إلى 85.
