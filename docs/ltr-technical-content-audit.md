# تدقيق المحتوى التقني LTR

## النطاق

تم تدقيق نقاط العرض المركزية بدل معالجة النصوص صفحةً صفحة:

- الدروس والأمثلة والتدريبات: `StandardLessonPage`، أنظمة الأعداد، البطاقات الثنائية.
- كارنوف وجداول الحقيقة: شبكة مشتركة، ترتيب Gray، ربط خلية الخريطة بصف جدول الحقيقة، وعناوين `A, B, V`.
- الاختبارات: السؤال، كود السؤال، إجابة الطالب، الإجابة النموذجية والشرح في الطالب والمعلم.
- أوراق العمل: التعليمات، التلميحات، خطوات الإجابة النموذجية.
- بايثون وskui: أوامر الخطوات، المخرجات المختلطة، iframe المعاينة.
- التصدير: HTML والمعاينة وصفحة offline وmanifest وبيانات المشروع.

## حالات التدقيق

تغطي اختبارات التقسيم والقيم المركزية:

- `A AND B` و`A OR B`.
- `101101` و`0xFF`.
- `row[1]` والمصفوفات المتداخلة.
- subscripts مثل `A₁`.
- أكواد Python والتعابير والجداول التقنية.

لا توجد استخدامات إنتاجية متبقية لـ `dir="auto"` في `src`. ويجب أن تمر القيم التقنية عبر المكونات المركزية، مع إبقاء النثر العربي RTL.

## ما لم يتغير

- لم تتغير قواعد النشر أو عدد الأيام المنشورة.
- لم تتغير المصادقة أو الصلاحيات أو إظهار حلول المعلم للطالب.
- لم تُفعّل PWA المعطلة ولم تتغير إعدادات Render أو آلية النشر.
- لم يتغير المحتوى العلمي؛ التغيير في بنية حقول العرض، وترتيب Gray الصحيح، وربط الخلايا.

## التغطية

- Unit: tokenizer، مكونات LTR، كارنوف، quiz renderers، ZIP/export وWebApp preview.
- Playwright: طالب، كارنوف، جدول الحقيقة، أنظمة الأعداد، ASCII/الثنائي، الحلقات/المصفوفات وskui.
- Visual: desktop لخرائط كارنوف والجداول، tablet لأنظمة الأعداد وASCII/الثنائي، mobile للحلقات/المصفوفات وskui؛ تشمل أسطحًا فاتحة وداكنة.

## القيود

- اتجاه تطبيق skui النهائي يمكن أن يغيّره المشروع نفسه عبر `App(direction=...)`؛ القيمة المصدّرة هي fallback.
- النصوص الحرة الجديدة التي لا تستخدم renderer المركزي تحتاج مراجعة محتوى.
- لقطات Playwright مرتبطة بمحرك Chromium والخطوط المتاحة في بيئة الاختبار.
