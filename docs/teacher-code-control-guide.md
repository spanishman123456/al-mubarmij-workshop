# دليل المعلم — التحكم في ظهور الكود

## أين أجد الأداة؟

- **لوحة المعلم** → زر «التحكم في ظهور الكود» → صفحة `/teacher/code-visibility`.
- **داخل مختبر بايثون** (الوضع الرسومي): شريط «الوضع الحالي للطالب» مع زر «تغيير الإعداد»
  الذي يفتح الصفحة مع تحديد المشروع الحالي مسبقًا.

## خطوات ضبط مستوى الظهور

1. اختر النطاق: **كل المشاريع (عام)** أو **مشروع محدّد** أو **يوم تدريبي**.
2. عند اختيار مشروع/يوم، حدّده من القائمة المنسدلة.
3. اختر أحد المستويات الثمانية.
4. (اختياري) اكتب سبب التغيير — يُحفظ في سجل التغييرات.
5. اضغط **حفظ وتطبيق**. ينعكس فورًا على الطلاب.

## المستويات التي تكشف الحل الكامل

المستويان 7 و8 يكشفان الحل الكامل للطالب. عند اختيار أحدهما تظهر **نافذة تأكيد**
توضّح النطاق والمشروع والطلاب المتأثرين قبل التفعيل.

## الأزرار

- **حفظ وتطبيق**: يطبّق المستوى المختار على النطاق.
- **إعادة للافتراضي**: يحذف تخصيص النطاق ويعيده للوضع العام/الافتراضي.
- **استرجاع السابق** / **تراجع عن الأخير**: يلغي آخر تغيير فعلي ويعيد القيمة السابقة.
- **معاينة كطالب**: يعرض ما سيراه الطالب فعليًا (وصف/تلميحات/كود/حل) دون أي تأثير
  على تقدّم الطلاب أو محاولاتهم.

## سجل التغييرات

كل تغيير يُسجَّل مع: الوقت، المعلم، النطاق والهدف، القيمة قبل/بعد، الإجراء، والسبب.
يظهر السجل أسفل الصفحة ويُستخدم للاسترجاع.

## ملاحظات مهمة

- تغييرات الظهور **لا تؤثّر** على `publishedDays` ولا على تقدّم الطلاب ولا على إعدادات النشر.
- الحل الكامل **لا يصل** إلى متصفّح الطالب إلا عند المستوى 8 (فوري) أو 7 (بعد المحاولة).
