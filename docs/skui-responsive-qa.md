# خطة QA للاستجابة والارتفاع والتمرير

## الهدف

ضمان أن تطبيق skui يملأ مساحة المعاينة بصورة مناسبة، دون تمريرين متداخلين أو عناصر مقطوعة، ويعمل باللمس ولوحة المفاتيح.

## مصفوفة المقاسات

| الفئة | المقاس الأساسي | مقاسات إضافية |
|---|---:|---:|
| Mobile صغير | 360×800 | 320×568 |
| Mobile كبير | 390×844 | 430×932 |
| Tablet عمودي | 768×1024 | 820×1180 |
| Tablet أفقي | 1024×768 | 1180×820 |
| Desktop | 1440×900 | 1280×720، 1920×1080 |

## قواعد الارتفاع

1. يوجد مالك تمرير رأسي واحد فقط.
2. WebApp المباشر يستخدم مساحة viewport المتبقية بعد Header دون iframe داخلي قابل للتمرير عند الإمكان.
3. المعاينة داخل المختبر تستخدم auto-height محدودًا أو fullscreen mode واضحًا.
4. المشروعات الطويلة تستخدم Panels داخلية مقصودة، لا تمرير صفحة داخل صفحة.
5. ظهور لوحة مفاتيح الجوال لا يحجب الحقل أو زر الإرسال.
6. النتائج والأزرار النهائية تبقى قابلة للوصول.

## حالات الاختبار

### كل مشروع تدريبي

- تحميل أولي.
- Focus على أول Input.
- كتابة طويلة.
- ظهور رسالة خطأ ونجاح.
- تكبير النص 200%.
- اتجاه RTL، ثم مكوّن LTR للأرقام عند الحاجة.

### كل مشروع نهائي

- Welcome.
- Main workspace.
- فتح Dialog/Drawer.
- تغيير المرحلة.
- نتيجة نهائية.
- Replay.
- fullscreen دخولًا وخروجًا.
- orientation عمودي/أفقي.

## معايير الوصول

- مساحة تفاعل لا تقل عن 44×44.
- ترتيب Tab منطقي.
- `focus-visible` واضح.
- لا يعتمد المعنى على اللون وحده.
- Contrast مناسب.
- Canvas لديه وصف بديل وControls مكافئة للكيبورد.
- الحركة تحترم `prefers-reduced-motion`.
- الأصوات اختيارية ومكتومة افتراضيًا في الاختبارات.

## Playwright المطلوب

لكل Prototype:

1. مشروع Desktop كامل.
2. مشروع Tablet كامل.
3. مشروع Mobile كامل.
4. Assertion أن `scrollWidth <= clientWidth`.
5. Assertion لعدم وجود عنصر تفاعلي خارج viewport أفقيًا.
6. فحص عدم وجود scroll containers متداخلة غير مصرح بها.
7. Screenshot لكل مشهد أساسي للمراجعة البصرية.
8. تشغيل بالكيبورد في مسار أساسي.

## إصلاح معماري مقترح

- إضافة `layout="workspace|split|map|game|training"` إلى `App/Scene`.
- إضافة قناة `content-size` من iframe إلى React عبر `ResizeObserver`.
- تحديد `viewportMode="auto|contained|fullscreen"`.
- فصل Header الخارجي عن مساحة التطبيق باستخدام CSS Grid (`auto 1fr`).
- منع `.root` من فرض `100vh` داخل iframe contained.
- استخدام container queries أو breakpoints موحدة للمكونات المتقدمة.

## بوابة النجاح

- لا تمرير مزدوج في أي مقاس أساسي.
- لا قص للأزرار والنتيجة.
- جميع السيناريوهات قابلة للتنفيذ باللمس والكيبورد.
- الفروق البصرية بين المقاسات مقصودة وموثقة.
