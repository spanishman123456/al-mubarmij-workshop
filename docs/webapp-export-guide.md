# دليل WebApp

اختر «تصدير WebApp ZIP» من مركز التصدير. تحتوي الحزمة على `index.html`,
`app.js`, `preview.html`, `main.py`, runtime محلي، metadata، وأصول المشروع.

فك الضغط وارفع المجلد إلى استضافة ثابتة أو شغله بخادم محلي. جميع المسارات نسبية
ولا تحتاج الحزمة إلى جلسة المنصة أو API المعلم أو اتصال CDN.
