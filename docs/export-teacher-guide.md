# دليل التصدير للمعلم

تظهر مشاريع الطلاب المرسلة في لوحة المعلم مع الكود ومعاينة skui المعزولة
وخيارات التصدير. شغّل المعاينة قبل التقييم، ولا تفتح ملفات غير موثوقة خارج
الحزمة.

سجل التصدير يعرض metadata والحالة فقط. بيانات الإدخال داخل التطبيقات لا تسجل.
ملفات Windows الرسمية يجب أن تكون موقعة وأن يطابق SHA-256 التقرير قبل التوزيع.
