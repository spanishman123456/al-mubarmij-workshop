# سياسة ظهور الكود والتلميحات (المرحلة الأولى)

أداة تتيح للمعلم التحكّم الفوري في مستوى ظهور الكود والتلميحات للطلاب دون تعديل
متغيّرات البيئة على Render ودون إعادة بناء أو نشر. تُحفظ الإعدادات في
`server/data/platform-settings.json` عبر `platformSettingsRepository` وتنعكس فورًا.

## المستويات الثمانية

| المستوى | المفتاح | الوصف | يكشف الحل؟ |
|--------|---------|-------|-----------|
| 1 | `hide` | إخفاء الكود كليًا (صفحة فارغة) | لا |
| 2 | `task-only` | عرض وصف المهمة فقط | لا |
| 3 | `hints-only` | عرض التلميحات فقط | لا |
| 4 | `starter` | عرض الكود الابتدائي + التلميحات (الافتراضي) | لا |
| 5 | `partial` | عرض كود جزئي بفراغات | لا |
| 6 | `steps` | عرض الكود خطوة بخطوة | لا |
| 7 | `full-after` | عرض الحل الكامل بعد إكمال المحاولة | نعم (بشرط) |
| 8 | `full-immediate` | عرض الحل الكامل مباشرة | نعم (فوري) |

- المستوى الافتراضي الآمن: **4** (`DEFAULT_CODE_VISIBILITY_LEVEL`).
- المستوى الاحتياطي عند فشل تحميل السياسة: **1 إخفاء الحل** (`FALLBACK_CODE_VISIBILITY_LEVEL`).
- المصدر: [`src/config/codeVisibilityPolicy.js`](../src/config/codeVisibilityPolicy.js).

## النطاقات والأولوية

النطاقات المدعومة في المرحلة الأولى: **عام**، **مشروع محدّد**، **يوم تدريبي**.

ترتيب الأولوية عند حساب المستوى الفعّال:

```
طالب > مجموعة > مشروع/نشاط > يوم > عام
```

في المرحلة الأولى تُطبَّق فعليًا: مشروع > يوم > عام. حقول الطالب/المجموعة/الجدولة
محفوظة كعناصر خاملة ليكون توسّع المرحلة الثانية إضافيًا دون إعادة هيكلة.

الدالة المرجعية: `resolveEffectiveLevel(target, policy)` في
[`src/config/codeVisibilityPolicy.js`](../src/config/codeVisibilityPolicy.js).

## آلية التطبيق الفوري

1. المعلم يحفظ الإعداد من `/teacher/code-visibility`.
2. الطلب `PUT /api/config/code-visibility` يكتب الحالة في ملف الإعدادات.
3. أي جلب لاحق للطالب عبر `GET /api/lab/:resourceId/allowed-content` يقرأ الحالة
   الجديدة مباشرة — لا حاجة إلى Build أو Deploy أو تعديل Render.

## المؤجّل للمرحلة الثانية

التخصيص لطالب محدّد، التخصيص لمجموعة، محرّر إخفاء الأسطر يدويًا، والجدولة الزمنية.
