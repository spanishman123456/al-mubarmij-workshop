# دليل المعلم لمشاريع SKUI

- اختبر نواتج الطلاب في المتصفح قبل توزيع أي حزمة.
- فضّل Web/PWA عند اختلاف أجهزة الطلاب؛ استخدم MSI/NSIS لمختبرات Windows.
- وزّع ملف `SHA256SUMS.txt` مع المثبتات، ووضّح هل الإصدار موقّع أم غير موقّع.
- لا تطلب من الطلاب تجاوز SmartScreen. وقّع إصدارات التوزيع المؤسسي بشهادة
  Authenticode موثوقة.
- راجع الكود والتفاعلات وحدود الوقت/الذاكرة. عزل worker وiframe طبقة دفاع،
  وليس بديلاً عن مراجعة المحتوى.
- احتفظ بأرشيف المصدر واسم المشروع والإصدار مع كل تسليم.

تشغيل workflow يدوي: حدّد اسم المنتج والإصدار والمعرّف ومسار `dist`. لإضافة
التوقيع، اضبط سري GitHub `WINDOWS_CERTIFICATE_BASE64` (ملف PFX بصيغة Base64)
و`WINDOWS_CERTIFICATE_PASSWORD`. يجب ضبطهما معاً.
